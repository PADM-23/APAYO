# 🌾 APAYO (아파요)

> **JunctionX Korea 2026 | Track: Microsoft & Gyeongsangbuk-do**
> 
> 
> 경북 외국인 계절근로자의 증상과 농작업환경 맥락을 공공데이터로 결합하여 원활한 의료 소통을 돕는 다국어 AI 기반 문진 iOS 솔루션
> 

---

## 📌 Problem & Background (기획 배경)

- **경북 농가와 외국인 계절근로자**: 경상북도는 고령화와 농촌 일손 부족으로 매년 수많은 외국인 계절근로자가 입국해 노동에 종사하고 있습니다.
- **의료 사각지대 및 언어 장벽**: 언어 소통 불가로 병원 방문이 지연되거나, 진료 시 본인의 증상 및 작업 환경(농약 살포 여부, 야외 작업 시간 등)을 의료진에게 정확히 전달하지 못해 적절한 치료 시기를 놓치는 문제가 발생합니다.
- **솔루션**: **APAYO**는 외국인 근로자가 모국어로 작성한 증상과 그림 카드를 기반으로 문진을 진행하고, **기상청 공공데이터(작업지 기온·습도·특보)**를 결합하여 **의료진용 표준 한국어 농작업 문진표** 및 **맞춤 병원 탐색**을 제공합니다.

---

## ✨ Key Features (주요 기능)

1. **🌐 다국어 증상 입력 & 그림 카드 매핑**
    - 필리핀어, 베트남어 등 다국어 텍스트 입력 지원
    - 증상 및 신체 부위 자동 추출 후 직관적인 일러스트레이션 카드 동시 제공
2. **🩺 표준 필수 문진 체크리스트 기반의 증상 수집**
    - 표준 의료 문진(통증 양상, 강도, 시작 시점, 복용 약 등) 기반의 증상 수집
3. **🚜 농작업 맥락 & 공공데이터(기상청) 결합**
    - 농약 노출, 기계 절상/낙상, 벌레 물림 등 농작업 특화 체크리스트
    - 사용자 위치 기반 기상청 API 연동 (작업 시간대 기온·습도·폭염경보 데이터 자동 결합)
4. **📋 의료진 전용 표준 한국어 문진표 생성**
    - 의료진이 빠르게 환자 상태를 파악할 수 있는 요약 리포트 (이미지 저장 / QR 공유 지원)
5. **🏥 주변 의료기관 및 응급실 탐색**
    - 공공데이터 기반(심평원/응급의료포털) 위치별 병의원 필터링 및 전화·길 안내 연결
